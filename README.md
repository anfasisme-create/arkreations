# ARK Social — Instagram X Full Feature Prototype

A futuristic Instagram-style app with core social features:
- Stories with viewed state and add-story action
- Feed with richer post cards (like, comment, share, save)
- Post composer with optional image URL upload field
- Desktop profile panel with stats (posts, likes, saved)
- DM panel with live sending and simulated quick reply
- Responsive mobile + laptop layout

## Run locally

```bash
python3 -m http.server 4173
```

Open: http://localhost:4173
